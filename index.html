Installer en 3 étapes

De zéro au premier message, en moins de deux minutes.

1

Ouvre une invite de commandes

Appuie sur Win, tape cmd, puis Entrée.

2

Colle la commande d'installation

Copie la ligne ci-dessous, colle-la dans le cmd et appuie sur Entrée :

> curl -fsSL https://raw.githubusercontent.com/Qays67/XozHub/main/install.bat -o "%TEMP%\xozhub-install.bat" && "%TEMP%\xozhub-install.bat"

Le script télécharge XozHub, l'installe dans C:\Users\vous\XozHub et ajoute le dossier au PATH tout seul. Tu verras « TERMINE ! » à la fin.

3

Ouvre un nouveau cmd et lance

Ferme la fenêtre, rouvres-en une nouvelle (pour que le PATH soit pris en compte), puis :

> xozhub

Au premier lancement, XozHub te demande ta clé API (Claude). Elle est enregistrée une seule fois dans %USERPROFILE%\.xozhub\config.json.

Une erreur pendant l'installation ? curl : (22) ... 404 = le fichier n'a pas pu être téléchargé (pas encore en ligne, proxy ou antivirus) : essaie la méthode PowerShell. 'curl' n'est pas reconnu = curl.exe absent : la méthode PowerShell fonctionne toujours. Et dans tous les cas, ouvre un nouveau cmd avant de taper xozhub.
Il faut une clé API. XozHub est le client, le modèle tourne chez le fournisseur. Crée une clé sur console.anthropic.com. Tu peux aussi brancher n'importe quelle API compatible OpenAI avec /setup.

Questions fréquentes

Tout ce qu'on me demande tout le temps.

La commande renvoie « curl : (22) ... returned error: 404 »

Le fichier n'a pas pu être téléchargé. Trois causes possibles : un antivirus ou un proxy qui bloque raw.githubusercontent.com, une connexion instable, ou un dépôt renommé. Utilise la méthode PowerShell (section Commandes) qui passe par un autre chemin réseau, puis réessaie depuis un nouveau cmd.

C'est quoi le rapport avec Claude ?

XozHub.GPT est un client : c'est le programme qui tourne sur ta machine et qui affiche l'interface. Le modèle, lui, tourne chez Anthropic (Claude Sonnet 4.6). C'est pour ça qu'il faut une clé API — exactement comme le site que tu m'as montré avec DeepSeek.

Où est stockée ma clé API ?

Dans %USERPROFILE%\.xozhub\config.json, sur ton disque. Elle n'est envoyée qu'à l'API du modèle que tu as choisi. Aucun serveur intermédiaire.

« xozhub n'est pas reconnu comme commande interne » — que faire ?

C'est Windows, pas XozHub : le PATH ne se rafraîchit pas dans un cmd déjà ouvert. Ferme la fenêtre, ouvre un nouveau cmd et réessaie. Vérifie avec xozhub --version.

Erreur 401 / clé invalide

Ta clé est mauvaise ou expirée. Relance xozhub setup pour la ressaisir.

Erreur 429 / quota

Tu as dépassé ton quota chez le fournisseur. Attends un peu ou vérifie ton crédit sur la console Anthropic.

Est-ce que ça marche avec un autre modèle ?

Oui. /setup puis option 2 : tu peux pointer vers n'importe quelle API compatible OpenAI (DeepSeek, Groq, Mistral, OpenRouter, un serveur local...).

Ça marche sur autre chose que Windows ?

Non, XozHub est fait pour l'invite de commandes Windows (batch + PowerShell natifs). Sur macOS ou Linux, utilise carrément le CLI officiel d'Anthropic.

Pourquoi l'interface ne ressemble pas aux captures ?

Le rendu des blocs et des couleurs dépend de la police de ton console. Pour le meilleur résultat, utilise Windows Terminal (police Cascadia Mono ou Consolas).
